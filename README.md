Notes App is a full-stack MERN application that lets users create, edit, and delete notes with persistent storage. It features user authentication, a clean and responsive UI, and stores notes securely in MongoDB. The app combines React on the frontend with Express and Node.js for the backend.

Key Features:

User authentication and profile management

Create, edit, and delete notes

Persistent data storage with MongoDB

Responsive, intuitive UI

Tech Stack:

MongoDB

Express.js

React

Node.js
